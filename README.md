Project Overview
The presentation covers three website case studies:
1. College Information and Admissions Website — institutional information, departments, courses, faculty, admissions, campus facilities, events, and contact details.
2. Healthy Food and Nutrition Website — nutritious recipes, ingredients, calorie information, food categories, and healthy eating tips.
3. Movie Review Website — movie posters, titles, ratings, genres, release years, and short descriptions.
Technologies Used
- HTML — structures webpage content.
- CSS — styles pages with colors, spacing, typography, and layouts.
- Flexbox — arranges cards and allows them to wrap on smaller screens.
Case Studies
Case Study 2: College Information and Admissions Website
A simple website for DR. RVR NRI University, including a navigation bar, welcome banner, departments, faculty, admissions, campus facilities, and contact information.

HTML elements covered: <!DOCTYPE html>, <html>, <head>, <title>, <style>, <body>, <header>, <nav>, <a>, <div>, headings, <p>, and <footer>.

CSS properties covered: background, color, font-family, margin, padding, text-align, display: flex, flex-wrap, gap, and border-radius.
Case Study 14: Healthy Food and Nutrition Website
A webpage presenting fruit salad, vegetable salad, and oatmeal in recipe cards, with ingredients, calorie values, and healthy eating tips.

HTML elements covered: <!DOCTYPE html>, <html>, <head>, <title>, <style>, <body>, <header>, headings, <p>, <div>, and <footer>.

CSS properties covered: font-family, background, color, text-align, margin, padding, display: flex, flex-wrap, gap, and border-radius.
Case Study 22: Movie Review Website
A movie webpage featuring Inception, Interstellar, and Oppenheimer, with posters, ratings, genres, release years, and brief descriptions.

HTML elements covered: <!DOCTYPE html>, <html>, <head>, <title>, <style>, <body>, headings, <div>, <img>, and <p>.

CSS properties covered: background, color, font-family, text-align, display: flex, justify-content: center, flex-wrap, gap, padding, width, height, object-fit: cover, and border-radius.
Learning Outcomes
- Understand how HTML structures a webpage.
- Apply basic CSS styling to improve appearance and readability.
- Organize content into cards and sections.
- Use Flexbox to create flexible layouts.
- Practice building webpages for different topics.
